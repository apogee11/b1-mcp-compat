# .NET 10, delivered as a single self-contained executable

Target customers have not kept Business One current, so their Windows Servers are often neglected. The connector is built on .NET 10 (LTS) and published as one self-contained win-x64 executable so nothing has to be installed. .NET 10 supports Windows Server 2012 and later (2012 and 2012 R2 only with Extended Security Updates). If a customer machine cannot run it, a `net48` host would be considered then, not before.
